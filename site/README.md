# Public pages for Deep Bounce

`index.html` (= `privacy-policy.html`) is the English Privacy Policy, a single self-contained responsive page
(no scripts, no external resources). Host this folder anywhere with HTTPS, for example:

- **GitHub Pages** (free): a *public* repository (GitHub Free cannot serve Pages from private repositories) →
  Settings → Pages → Deploy from branch → folder `/site` or root. URL:
  `https://vladislavdrucok-tech.github.io/<repo>/privacy-policy.html`.
- **Google Sites** (free): paste the text into a new site and publish.

Before publishing, replace `[EFFECTIVE DATE]`, `[DEVELOPER NAME]` and `[CONTACT EMAIL]`.

`app-ads.txt` must be at the root of a domain (for GitHub Pages: a repository named
`vladislavdrucok-tech.github.io`), see `app-ads.txt.template`.
