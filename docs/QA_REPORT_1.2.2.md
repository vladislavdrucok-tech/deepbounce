# Deep Bounce 1.2.2 — фінальний QA-звіт

Версія 1.2.2, **versionCode 10**, пакет `com.deepbounce.game`, target SDK 36, min SDK 24, Godot 4.5.1.
Гілка `release/1.2.2`. Позначки: **PASS** — перевірено й працює; **FAIL** — перевірено й не працює;
**NOT TESTED** — перевірка не проводилась (причина вказана). Непроведені перевірки PASS не позначаються.

versionCode 10 замість 9: попередній AAB 1.2.2 мав код 9; якщо його вже завантажували в Play Console, повторний код
відхилили б. Код 10 приймається в будь-якому разі (Google Play вимагає лише зростання коду).

## 1. Що виправлено в 1.2.2

| Проблема | Причина | Виправлення |
|---|---|---|
| **Перевірка підпису покупок відхилила б кожну справжню покупку** | Google Play підписує `Purchase.originalJson` за схемою **SHA1withRSA**; гра перевіряла лише SHA-256 (старий тест сам підписував SHA-256 і не міг цього помітити) | `scripts/store.gd`: SHA-1 (+ SHA-256 про запас); `check_purchase()` звіряє підписаний JSON із покупкою (токен, пакет, товари, стан PENDING); контрольні вектори OpenSSL, звірені з Java `SHA1withRSA` |
| Play Console: застарілі edge-to-edge API (Android 15) | Шаблонна активність Godot при кожному поверненні в гру викликала `enableImmersiveMode/enableEdgeToEdge(…, true)` → `Window#setDecorFitsSystemWindows`, при запуску — `EdgeToEdge.enable()` | Власна `tools/android/template/GodotApp.java`: панелі ховаються лише через `WindowInsetsControllerCompat` |

| Планшет вважався телефоном (знайдено на емуляторі) | Godot на Android віддає DPI на момент запуску; нова ширина приходить після події зміни розміру | Плагін повертає `smallestScreenWidthDp` Android; повторна перевірка раз на секунду |
| Подвійний відступ під системні панелі (Android ≤ 14, видимі панелі) | Плагін брав відступи всього вікна | Відступи обрізаються до вікна гри (`DeepBouncePlay.overlap`) |
| Широкі вікна: фон обривався | Фон і стіни на 9:16 | Стіни шахти по боках, фон точно під видиму область |
| Немає посилання на Terms of Use у грі | — | Налаштування → «Умови використання» (12 мов) |
| Production-збірку можна було зібрати без ключа ліцензування | — | `build_release.sh` відмовляє збирати з `use_test_ads=false`, поки `check_store_ready.sh` не READY |

## 6. Не перевірено (NOT TESTED) і чому

| Що | Причина |
|---|---|
| Android 13, 15, 16 | немає KVM і замало диска для їхніх образів; реально перевірено лише Android 11 |
| Справжній телефон, планшет, складаний | фізичних пристроїв немає |
| Справжні покупки, PENDING, refund у Google Play | потрібні Play-збірка з треку тестування й тестувальники ліцензій |
| Показ реклами, форма UMP, повернення з реклами | лише на пристрої з мережею і Play-збіркою |
| Play Games | не налаштовано в Play Console |
| Чи зникли попередження Play Console | видно лише після завантаження AAB |
| Оновлення через сам Google Play | потрібне завантаження в трек |
