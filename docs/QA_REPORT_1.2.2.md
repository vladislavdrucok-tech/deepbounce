# Deep Bounce 1.2.2 — фінальний QA-звіт

Версія 1.2.2, **versionCode 10**, пакет `com.deepbounce.game`, target SDK 36, min SDK 24, Godot 4.5.1.
Гілка `release/1.2.2`. Позначки: **PASS** — перевірено й працює; **FAIL** — перевірено й не працює;
**NOT TESTED** — перевірка не проводилась (причина вказана). Непроведені перевірки PASS не позначаються.

versionCode 10 замість 9: попередній AAB 1.2.2 мав код 9; якщо його вже завантажували в Play Console, повторний код
відхилили б. Код 10 приймається в будь-якому разі (Google Play вимагає лише зростання коду).

## Завдання 3/5 — Android + ігровий QA (26.11)

| Проблема | Що зроблено | Перевірка |

### Android 15/16 — перевірки без пристрою
- **Сторінки 16 КБ** (вимога Google Play для target API 35+): усі `.so` (arm64-v8a, x86_64) мають вирівнювання LOAD
  `0x4000`; `zipalign -c -P 16` — Verification successful. **PASS**
- **Застарілі edge-to-edge API**: наша активність їх не викликає; виклики є лише в бібліотеках (androidx core/activity/
  browser/splashscreen, Godot, Google Mobile Ads/UMP). Play Console може показувати попередження «uses deprecated APIs
  for edge-to-edge» через код бібліотек — прибрати його без оновлення бібліотек неможливо; на роботу не впливає.
- **Android 16, великі екрани**: система ігнорує фіксацію орієнтації на sw ≥ 600 dp — гра там і так дозволяє поворот,
  на телефонах лишається портрет.
- **Емулятор Android 16 (API 36)**: образ завантажено, AVD створено, система стартувала (`release=16 sdk=36`), але без
  KVM (програмна емуляція) Watchdog Android раз у раз убиває system_server (`Blocked in handler on main thread for 62s`),
  зокрема під час встановлення APK — навіть після підвищення `system_server_watchdog_timeout_ms` і в багатопотоковому
  режимі QEMU. Гру встановити не вдалося → **Android 16 — NOT TESTED** (ні на емуляторі, ні на пристрої).
- **Емулятор Android 11 з тестовим APK цього завдання** (виправлення «Назад», виріз камери, планшет, складаний, пам'ять):
  після скидання даних AVD (бракувало диска для образу Android 16) емулятор завантажувався, але всі 6 спроб
  встановлення APK зірвались — служба пакетів емулятора падала (`Can't find service: package`). Тож у цьому завданні
  на емуляторі нічого нового не перевірено: **NOT TESTED**. Попередні результати Android 11 (розділ 3, збірки 1.2.2 від
  25.11) стосуються коду без зміни «Назад»; решта Android-коду з того часу не змінювалась.

### Ризики для Android 15/16
1. «Назад» на Android 16 — виправлено в коді, на пристрої не перевірено (найважливіша перевірка на справжньому телефоні).
2. Edge-to-edge (обов'язкове з target API 35): гра малює під панелями й вирізом, кнопки тримає в безпечній зоні з
   `systemBars | displayCutout`; перевірено на ПК і Android 11, на Android 15/16 — ні.
3. Повернення з повноекранної реклами: панелі ховаються знову в `onResume`/`onWindowFocusChanged`; з реальною рекламою
   не перевірено.
4. Попередження Play Console про застарілі edge-to-edge API — з коду бібліотек, не з гри.
5. Сторінки 16 КБ — вирівняно, ризику немає.
